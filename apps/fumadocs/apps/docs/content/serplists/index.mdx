This documentation app is the source of truth for UI integration readiness.

Use it to inventory:

- routes and page records
- feature behavior and rules
- reusable UI block expectations
- domain vocabulary that the redesigned UI must preserve

The working rule is simple: describe the product as content, structure, and behavior, not as the current UI implementation.

## Start Here

- Read the [Overview](/docs/overview) for the operating model.
- Use the [Page Inventory Template](/docs/inventory/page-template) for route records.
- Use the [Feature Record Template](/docs/features/feature-template) for reusable behavior.
