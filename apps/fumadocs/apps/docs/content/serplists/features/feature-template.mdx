Use this as the copy-paste template for reusable feature records.

## Frontmatter Contract

| Field | Use |
| --- | --- |
| `recordType` | Set to `feature` |
| `featureId` | Stable feature identifier |
| `status` | `draft`, `seeded`, `in-review`, `approved` |
| `owner` | Responsible team or role |
| `relatedRoutes` | Route IDs or paths using the feature |
| `relatedBlocks` | UI block IDs linked to the feature |
