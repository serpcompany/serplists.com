Feature records capture behavior once and link it back to the pages that use it.

Use this section when a flow appears in multiple places or when the redesign could accidentally preserve the screen but break the logic.

Examples:

- copy or save template
- start run from template
- run execution progress rules
- billing and upgrade gating
- share run behavior

Start new records from [Feature Record Template](/docs/features/feature-template).
