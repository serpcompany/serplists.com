Use this as the copy-paste template for every route record.

## Frontmatter Contract

| Field | Use |
| --- | --- |
| `recordType` | Set to `page` |
| `routeId` | Stable route identifier |
| `currentUrl` | Current canonical URL |
| `futureUrl` | Expected URL after integration, if different |
| `routePattern` | Dynamic route pattern |
| `pageType` | Template or page family |
| `primaryEntity` | Main entity represented by the page |
| `access` | Public, authenticated, guest-share, admin, etc. |
| `status` | `draft`, `seeded`, `in-review`, `approved` |
| `owner` | Responsible team or role |
| `relatedFeatures` | Feature record IDs linked to this page |
| `relatedBlocks` | UI block record IDs linked to this page |

## Metadata Guidance

For public pages, capture the real template and schema expectations.

For private app pages, capture whether the route should remain:

- `noindex`
- tokenized or private
- canonical-less or non-shareable

## Schema Guidance

Keep schema documentation at the template level, not the implementation-snippet level.

Document:

- which schema family applies
- which fields matter
- where the data comes from

Avoid documenting raw JSX or script injection details here.
