## Core Terms

- `Template`: reusable source definition for a process
- `Run`: execution copy created from a template
- `Public template`: published template visible on public routes
- `Shared run`: guest-accessible run view reached by token
- `Section`: ordered grouping inside a template or run
- `Item` or `task`: ordered executable unit inside a section
- `Content block`: ordered content entry inside an item
- `Sub-item`: nested checkbox-style step inside a `subItems` content block

## Route Families

- `Public discovery`: browseable library and creator surfaces
- `Public detail`: evaluation surface for a single template
- `Private console`: authenticated workspace surfaces
- `Execution`: run completion surfaces for private and shared contexts

## Authoring vs Execution

- `Authoring`: editing the reusable source template
- `Execution`: completing a live run copy derived from a template

This distinction must remain explicit in the redesigned UI.
