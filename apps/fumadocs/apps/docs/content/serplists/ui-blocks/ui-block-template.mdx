Use this template when a repeated UI block is important enough to document independently.

## Frontmatter Contract

| Field | Use |
| --- | --- |
| `recordType` | Set to `ui-block` |
| `status` | `draft`, `seeded`, `in-review`, `approved` |
| `owner` | Responsible team or role |
| `relatedRoutes` | Pages using this block |
| `relatedFeatures` | Features supported by this block |

## Suggested Sections

- Purpose
- Where it appears
- Inputs or slots
- Required states
- Variants
- Accessibility notes
- Related feature records
- Related page records
- Integration QA checks
