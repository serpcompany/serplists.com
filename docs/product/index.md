# Product Specs

What the product does today, from the user's point of view. Product principles and
vocabulary are in [PRODUCT_SENSE.md](../../CONTEXT.md). `pnpm run docs:check`
fails if a spec is missing from this list.

- [Auth and account](account.md): sign-up, sign-in, Account Settings, and public Profiles.
- [Dashboard navigation](dashboard.md): the console routes in Personal and in each Organization.
- [Templates](templates.md): creating, editing, sharing, exporting and moving Templates.
- [Runs and sharing](runs.md): starting, working through and sharing Runs.
- [Personal and Organization contexts](contexts.md): which context owns what, and what each role may do.
- [MCP changes for agents](mcp.md): the Run Key MCP endpoint's release notes.
- [Error contract](api-errors.md): how the API reports errors.
- [Pricing and entitlements](pricing-and-entitlements.md): Free, Pro, and paid
  Organization capabilities, limits, upgrade triggers, and the enforcement contract.
- [Portable templates](portable-templates.md): the import/export and authoring
  format, with copy-paste examples.
